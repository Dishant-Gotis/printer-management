# Module 4 — Windows Printing

## Objective

Discover local Windows printers, allow printer selection and settings, submit the final PDF as one print job, and report progress.

## Tasks

- [ ] Printer discovery
- [ ] Default printer detection
- [ ] Printer selection UI
- [ ] Windows printer status
- [ ] Print settings model
- [ ] Copies
- [ ] Paper size
- [ ] Orientation
- [ ] Page range
- [ ] Scaling
- [ ] Windows print submission
- [ ] Print progress
- [ ] Spooler submission status
- [ ] Offline/unavailable printer errors
- [ ] Print cancellation where supported
- [ ] Printing tests and manual printer verification

## Completion criteria

- Installed printers are discovered.
- The default printer is selected when available.
- Users can select another printer.
- The final combined PDF is submitted as one Windows print job.
- Unsupported settings are handled explicitly.
- Submission and failure states are visible to the user.
