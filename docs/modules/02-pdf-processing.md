# Module 2 — PDF Processing

## Objective

Validate, count, and merge intermediate PDFs into one final PDF while preserving the exact order selected by the user.

## Tasks

- [ ] PDF validation
- [ ] PDF page counting
- [ ] PDF merging
- [ ] Final combined PDF generation
- [ ] Ordered print-job manifest
- [ ] Mixed page-size handling policy
- [ ] Corrupted-PDF error reporting
- [ ] Single-file PDF handling
- [ ] PDF processing tests

## Completion criteria

- Valid PDFs are accepted.
- Corrupted or unreadable PDFs are rejected clearly.
- Page counts are accurate.
- Merged output follows UI order exactly.
- The final combined PDF is valid and can be opened by a standard PDF viewer.
- Tests cover PDFs, converted files, mixed formats, and interleaved file types.
