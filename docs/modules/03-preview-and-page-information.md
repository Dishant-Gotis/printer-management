# Module 3 — Preview and Page Information

## Objective

Give the user confidence in the final print job before submitting it to Windows printing.

## Tasks

- [ ] Display page count for each supported file where available
- [ ] Display final combined page count
- [ ] Add final PDF preview
- [ ] Add preview loading and error states
- [ ] Add preview refresh after reordering
- [ ] Add final PDF download/open action
- [ ] Add preview tests

## Completion criteria

- The preview reflects the current file order.
- The displayed page count matches the generated PDF.
- Preview failures are visible and actionable.
- Preview never triggers printing automatically.
