# Module 6 — Release and Distribution

## Objective

Build and distribute a downloadable Windows application that does not require users to install development tools.

## Tasks

- [ ] Release configuration
- [ ] Self-contained `win-x64` publish
- [ ] Single-file executable publish evaluation
- [ ] Application icon
- [ ] Version metadata
- [ ] Installer generation
- [ ] Uninstaller
- [ ] Clean-machine installation test
- [ ] Installed application launch test
- [ ] Code-signing evaluation
- [ ] Release artifact verification
- [ ] Automated update support
- [ ] Update rollback/failure handling

## Completion criteria

- A user can download and install the application on a supported Windows machine.
- The user does not need the .NET SDK, Python, or development tools.
- The application launches from the installed shortcut.
- Uninstallation works.
- Release artifacts are versioned and reproducible.
- Updates do not destroy user settings or active jobs.
